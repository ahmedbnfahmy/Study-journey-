## What is AWS?

Amazon Web Services — cloud platform for compute, storage, databases, networking, and more.

## Core services to know

- **EC2** — virtual servers
- **S3** — object storage
- **RDS** — managed relational databases (e.g. PostgreSQL)
- **Lambda** — serverless functions
- **IAM** — users, roles, permissions
- **VPC** — isolated network
