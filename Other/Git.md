## What is Git?

Distributed version control — track changes, branch, merge, collaborate via remotes (e.g. GitHub).

## Core concepts

- **Repository** — project history
- **Commit** — snapshot of changes
- **Branch** — parallel line of development
- **Merge / rebase** — integrate branches
- **Remote** — shared copy (origin)

## Commands to know

- `git status`, `git add`, `git commit`, `git push`, `git pull`
- `git branch`, `git checkout` / `git switch`, `git merge`
- `git log`, `git diff`, `git stash`
