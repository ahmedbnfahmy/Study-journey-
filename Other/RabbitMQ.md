## What is RabbitMQ?

Message broker — producers send messages to queues; consumers receive them asynchronously. Decouples services.

## Core concepts

- **Producer** — sends messages
- **Queue** — buffer that holds messages
- **Consumer** — receives and processes messages
- **Exchange** — routes messages to queues (direct, fanout, topic, headers)
- **Binding** — link between exchange and queue

## When to use

- Background jobs, event-driven architecture, load leveling, microservice communication
